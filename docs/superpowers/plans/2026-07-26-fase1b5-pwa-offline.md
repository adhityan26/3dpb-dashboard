# Fase 1b-5 — PWA & Offline — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `apps/saas` (Slizebiz) installable as a PWA and let its 4 core authenticated pages be reopened without network once visited — using Serwist, without touching NextAuth's `database` session strategy.

**Architecture:** A Serwist service worker (`app/sw.ts`) precaches the Next.js build output and layers `NetworkFirst` runtime caching (via Serwist's `defaultCache`) on top for navigations to `/`, `/kalkulator`, `/kalkulator/[id]`, `/settings` — with explicit `NetworkOnly` exclusions for `/login`, `/login/verify`, `/admin`, `/beli`, and `/api/*` placed before `defaultCache` in the matcher array (first-match-wins). A custom `/offline` fallback page covers navigation cache-misses. A `web app manifest` + generated PNG icons make the app installable. An `UpdateBanner` component (via `@serwist/window`) lets the user opt into activating a newly-downloaded service worker instead of silently swapping it. `LogoutButton` clears Cache Storage on sign-out so a cached page shell (which embeds the user's email) can't be reopened offline after logout on a shared device.

**Tech Stack:** Next.js 16 App Router, Serwist 9.5.x (`@serwist/next`, `serwist`, `@serwist/window`), `sharp` (one-time icon generation script, not part of the build), vitest + `@testing-library/react`.

- **Do not modify `packages/kalkulator-core`.**
- Exactly these 4 routes get runtime-cached for offline reopen: `/`, `/kalkulator`, `/kalkulator/[id]`, `/settings`. Exactly these are hard-excluded (`NetworkOnly`, never cached): `/login`, `/login/verify`, `/admin`, `/beli`, `/api/*`.

- Two things are explicitly flagged as unverified against the real `serwist` package and MUST be checked during Task 6, not assumed: (1) whether `Serwist`'s `skipWaiting: false` mode already wires up the `"SKIP_WAITING"` message listener automatically, and (2) whether Serwist's `defaultCache` caches redirected navigation responses (relevant to session-expiry redirects landing under a cached route's key).
- Out of scope entirely: an online/offline UI indicator (deferred to the future Subscribe/cloud phase), any session-strategy migration, cloud sync, push notifications, background sync.

```js
#!/usr/bin/env node
// Dijalankan SEKALI secara manual: node scripts/generate-pwa-icons.mjs
// Hasil PNG-nya di-commit ke git — BUKAN bagian build/CI (lihat spec §Manifest & ikon).
import sharp from "sharp";
import path from "path";
import { fileURLToPath } from "url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const publicDir = path.join(__dirname, "..", "public");
const svgPath = path.join(publicDir, "logo.svg");

async function main() {
  await sharp(svgPath).resize(192, 192).png().toFile(path.join(publicDir, "icon-192.png"));
  await sharp(svgPath).resize(512, 512).png().toFile(path.join(publicDir, "icon-512.png"));

  // Ikon maskable: logo diperkecil ke 320x320 (padding ~20% tiap sisi) di atas kanvas
  // 512x512 solid, supaya tak terpotong area aman adaptive-icon di Android/iOS.
  const logoBuffer = await sharp(svgPath).resize(320, 320).png().toBuffer();
  await sharp({
    create: { width: 512, height: 512, channels: 4, background: "#080818" },
  })
    .composite([{ input: logoBuffer, gravity: "center" }])
    .png()
    .toFile(path.join(publicDir, "icon-maskable-512.png"));

  console.log("Ikon PWA dibuat: icon-192.png, icon-512.png, icon-maskable-512.png");
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

- [ ] **Step 6: Write `app/sw.ts`, self-scoping the webworker lib via a triple-slash directive (not the project tsconfig)**

Create `apps/saas/app/sw.ts`:

```ts
/// <reference lib="webworker" />
import { defaultCache } from "@serwist/next/worker";
import { NetworkOnly, Serwist } from "serwist";
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

declare const self: ServiceWorkerGlobalScope;

// 4 halaman inti yang boleh di-cache (lihat Global Constraints) TIDAK perlu daftar
// eksplisit di sini — cukup kecualikan yang TIDAK boleh, sisanya jatuh ke defaultCache.
const EXCLUDED_PREFIXES = ["/login", "/admin", "/beli", "/api/"];

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: false,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    {
      matcher: ({ sameOrigin, url }) =>
        sameOrigin && EXCLUDED_PREFIXES.some((prefix) => url.pathname.startsWith(prefix)),
      handler: new NetworkOnly(),
    },
    ...defaultCache,
  ],
  fallbacks: {
    entries: [
      {
        url: "/offline",
        matcher: ({ request }) => request.destination === "document",
      },
    ],
  },
});

serwist.addEventListeners();
```

Create `apps/saas/components/UpdateBanner.tsx`:

```tsx
"use client";
import { useEffect, useState } from "react";

type SerwistLike = { messageSkipWaiting: () => void };

export function UpdateBanner() {
  const [waiting, setWaiting] = useState(false);
  const [serwist, setSerwist] = useState<SerwistLike | null>(null);

  useEffect(() => {
    if (typeof navigator === "undefined" || !("serviceWorker" in navigator)) return;
    let cancelled = false;
    import("@serwist/window").then(({ Serwist }) => {
      if (cancelled) return;
      const sw = new Serwist("/sw.js");
      sw.addEventListener("waiting", () => setWaiting(true));
      sw.addEventListener("controlling", () => window.location.reload());
      sw.register();
      setSerwist(sw);
    });
    return () => {
      cancelled = true;
    };
  }, []);

  if (!waiting) return null;

  return (
    <div
      className="fixed top-0 inset-x-0 z-[60] flex items-center justify-center gap-3 py-2 px-4 text-[13px]"
```

```tsx
"use client";
import { signOut } from "next-auth/react";
import { useTheme } from "next-themes";

// Best-effort: bersihkan Cache Storage service worker sebelum logout, supaya shell
// halaman ber-auth yang di-cache (berisi email user) tak bisa dibuka lagi offline
// oleh orang lain yang pakai device yang sama setelah user ini keluar.
async function clearServiceWorkerCaches() {
  try {
    if (typeof caches === "undefined") return;
    const keys = await caches.keys();
    await Promise.all(keys.map((key) => caches.delete(key)));
  } catch {
    // Cache API tak tersedia/gagal — logout tetap lanjut normal.
  }
}

/** Tombol keluar gaya control-island dashboard: lingkaran 32px dengan glyph power. */
export function LogoutButton({ className = "" }: { className?: string }) {
  const { resolvedTheme } = useTheme();
  const isDark = resolvedTheme !== "light";
  return (
    <button
      type="button"
      onClick={async () => {
        await clearServiceWorkerCaches();
        signOut({ callbackUrl: "/login" });
      }}
      title="Keluar"
      aria-label="Keluar"
      className={`w-[32px] h-[32px] rounded-full flex items-center justify-center text-sm transition-colors hover:bg-red-500/10 ${className}`}
      style={{ color: isDark ? "rgba(255,255,255,0.3)" : "rgba(30,27,75,0.28)" }}
    >
      ⏻
    </button>
  );
}
```
